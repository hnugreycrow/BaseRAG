# 星澜云商务报价与合同操作手册

文档编号：XL-SALES-018  
版本：3.0  
生效日期：2026-06-08  
状态：现行

## 适用范围

本手册适用于星芽版、星河版、星海版及 API 扩展包的企业客户报价、合同审批、签署和交接。标准套餐能力与标价以《星澜云协作产品套餐说明》为准，本手册只规定商务操作流程，不改变产品配额。

渠道转售、政府集中采购和免费公益项目使用独立流程。销售人员不得为了绕过审批而把同一客户、同一采购目的的订单拆成多份合同。

## 商机登记

销售首次确认客户存在明确预算和预计采购时间后，应在 2 个工作日内创建商机。商机编号格式为 `OPP-26-` 加六位数字。登记时至少填写客户法定名称、预计套餐、用户数量、预计合同额、采购方式和计划签约日期。

同一客户的续费与新增扩容应建立不同商机，但必须互相关联。仅有咨询邮件、没有预算或采购时间的信息不得标记为“已验证商机”。

## 标准报价

报价单默认有效期为 30 个自然日。报价超过有效期后，客户即使已经口头确认也需要重新生成报价；重新生成时使用当日有效的产品价格和折扣政策。

报价必须列出套餐名称、用户数量、服务期限、未税金额、税率和含税总额。API 扩展包应单独列项，代码为 `API-BURST-26`。任何套餐都不得写成“无限 API 调用”。

## 折扣审批

折扣以现行未税标准价为基准计算，多个优惠不能先后叠加以规避审批。

| 折扣幅度 | 最低审批人 |
| --- | --- |
| 不超过 8% | 销售经理 |
| 超过 8% 且不超过 15% | 销售总监 |
| 超过 15% 且不超过 22% | 销售总监、财务负责人 |
| 超过 22% | 商务委员会 |

恰好 8% 由销售经理审批，恰好 15% 由销售总监审批，恰好 22% 需要销售总监和财务负责人审批。免费延长服务期、赠送扩展包和免收实施费都应折算为折扣后再判断审批档位。

## 付款条件

标准付款条件为合同生效后 15 个自然日内一次性支付全年费用。客户要求 30 日账期时，需要财务信用审核；超过 30 日但不超过 60 日的账期还需财务负责人批准。公司不接受超过 60 日的标准账期，政府采购法定流程除外。

销售不得在合同外通过邮件承诺延迟付款、现金退款或超出服务等级协议的赔偿。

## 合同模板与非标准条款

标准合同模板编号为 `CTR-CLOUD-2026.2`。客户仅修改联系人、地址、购买数量和开票信息，不视为非标准法律条款。

修改责任上限、知识产权归属、数据处理范围、自动续费、争议解决地或保密期限时，必须由法务审批。涉及客户个人数据时还应签署数据处理附件，附件编号为 `DPA-CN-2026.1`，并由隐私负责人复核。

任何一方上传的扫描签章页必须与最终审批版本校验页数和文件哈希。签署后发现正文版本不一致的，不得通过替换归档文件修正，应立即暂停订单并联系法务。

## 签署与归档

公司优先使用电子签署平台。合同双方完成签署后，销售运营应在 1 个工作日内把最终合同、审批记录和报价单关联到同一商机。合同正本的保留期限按《业务记录保留制度》执行。

合同尚未完成双方签署时，不得把商机改为“已成交”。客户采购订单不能替代双方签署的合同，除非法务已为该客户批准采购订单模式。

## 交付交接

订单到账或信用账期获批后，销售应创建 `CS-HANDOVER` 交接单。交接单至少包含租户法定名称、套餐、用户数、合同起止日期、客户管理员、特殊条款和已承诺的上线日期。

客户成功经理应在收到完整交接单后的 2 个工作日内确认接收。如果信息不完整，应退回并列明缺失字段；退回不代表合同失效，但上线计时从完整交接单被接收后开始。

## 禁止事项

- 不得承诺尚未正式发布的“星云版”。
- 不得把月度 API 配额描述为永久累计额度。
- 不得用个人网盘传输合同、身份证明或客户数据。
- 不得在审批完成前向客户发送盖章版报价。
- 不得将客户口头意向记录为已经签署。
